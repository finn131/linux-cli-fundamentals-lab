# Linux CLI Fundamentals Lab

Hands-on Linux Command Line Interface (CLI) lab. Mulai dari navigasi dasar sampai analisis output perintah.

## Environment
- OS: Arch Linux
- Kernel: 7.2.11-arch1-1
- Shell: zsh
- User: nyxx

## Struktur
```
.
├── README.md
├── docs/
│   └── learning-outcome.md

└── labs/

    ├── 02-file-management/
    │   └── evidence/
    ├── 03-basic-linux-command/
    │   └── evidence/
    ├── 04-file-permissions/

```

## Cara Mulai
1. Baca `docs/learning-outcome.md` untuk paham tujuan tiap lab.
2. Ikuti langkah-langkah di README masing-masing folder `labs/`.
3. Jalankan perintah di terminal, catat output ke folder `evidence/` (screenshot atau `tee`).
4. Untuk contoh script, lihat `scripts/system-info.sh`.
